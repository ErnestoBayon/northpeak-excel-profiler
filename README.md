# NorthPeak Excel Profiler

A standalone strategic-intelligence HTML report generated for a NorthPeak business analysis engagement — a self-contained, shareable snapshot of the underlying Excel-based data profiling and analysis.

## Contents

- `NorthPeak_Strategic_Intelligence_final.html` — the final rendered report, viewable directly in any browser (no server required).

## About

- This project showcases how a raw Excel dataset can be profiled and turned into a polished, presentation-ready strategic intelligence report. It's part of a broader portfolio of data analysis and business intelligence work.
